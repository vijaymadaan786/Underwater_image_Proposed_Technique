Dataset


The dataset used in this research was obtained from the publicly available TURBID Dataset.

The link of original TURBID dataset is publicly available: http://amandaduarte.com.br/turbid/

For the complete dataset and the original dataset description, please refer to the official TURBID Dataset repository and the publication cited below.
